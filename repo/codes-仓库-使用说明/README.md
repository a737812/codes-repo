# codes 仓库 · 使用说明

codes 仓库是给开发者分享小软件和开源项目的地方。三条下载线自动测速选最快，不限速、不排队。

## 三个区

- **codes 上传区**：任何人登录后都能传，文件存在我们自己的存储里。
- **GitHub / Gitee 镜像区**：这两个区的内容是镜像，同一份文件会同时存在于三条线上。

## 三条下载线

| 线路 | 适合 |
|---|---|
| 萌盘 | 国内直连，稳定 |
| GitHub | 海外线路，raw 直链 |
| Gitee | 国内节点，通常最快 |

点下载时会同时测三条线的速度（只读前 128KB，不浪费流量），自动选最快的。

## 上传规则

- 单文件最大 90MB；
- 20MB 以内的文件会自动同步到 GitHub 和 Gitee，三条线都能下；
- 超过 20MB 只走萌盘线（两家 API 对单文件有限制）。

## 支持的分类

项目、Android（apk）、Windows（exe/msi）、Linux（按发行版分：Debian/Ubuntu、Arch、Fedora、Alpine、其它）、工具。

每个项目可以标注许可证（MIT / Apache-2.0 / GPL-3.0 …）和开源/闭源。
